# 世界観・執筆方針

## ㉕ F22 本文文体・描写リズムの共通基準（2026-10-31採用）

**位置づけ：** 本節はF13（三人称限定の視点）、F20（口調・呼称の照合）、F21（強い被弾と連係）を、**実際の小説の文章に落とし込むための文体正本**。設定資料の説明文や⑭・⑳のプロット記述をそのまま小説の語りにしない。章ごとの加筆・削除・攻防の具体的な拳順は、後続の独立した「改稿修正一覧」で管理し、本節では固定しない。

### 基本文体と視点

- **現代的で読みやすい日本語小説の地の文**を基調とする。地の文は原則「だ・た」調で、主人公に近い三人称一元。主人公の固有名を付けず「彼」または主語省略を使い分ける。ただし主語を省いた結果、拳を出した人物・受けた人物が分からなくなる文章は避ける。
- 「来る。」「遅い。」など主人公の感覚に重なる**短い現在形・自由間接的な一文**は使用できる。長い一人称独白へ突然切り替えず、同じ場面で複数人の本心を直接説明しない。第5章の柚葉視点など既存F13の例外を保持。
- 「彼は」「主人公は」の連呼も、全てを主語省略することも避け、地の文の焦点が追える範囲で文をつなぐ。人物の声・拳・足・視線に沿う自然な段落構成とし、**一文の文字数・段落数・擬音の回数を数値で固定しない**。
- 描写の細かさは作品全体で一定にしない。**重要な命中、連係の崩れ、心情の転換**に文章量を配分し、軽いジャブ・移動・会話は必要なら簡潔にする。

### 場面ごとに変える文章の速度

| 場面 | 文体とリズム | 感覚・情報の優先 |
|---|---|---|
| **表営業・日常** | 自然な長さの文と会話を交互に置き、柔らかく明るいテンポ | 店内の音、食器、服装、表情、相手との距離、居心地の変化。全員の説明を一度に詰め込まない |
| **裏への招待・攻防の前** | 会話や短い沈黙を利用し、緊張に応じて文を短くする | グローブ、相手の構え、息の速さ、主人公が自分で選ぶ言葉 |
| **スパー・速い連係** | 接近や打ち分けは短めの文で切り替え、**実際に身体へ届いた重要な拳では身体反応を詳述**。短文だけの機械的な羅列にしない | 起点→空振り／ガード／命中→衝撃→呼吸・腕・足→次の一手。主人公が見えなかった技の詳細を実況しない |
| **重さ・間で追い詰める攻防** | 命中のあとに余韻や次を待つ時間を置く。少ない拳でも文章の圧を高める | 身体に残る重み、反撃の遅れ、返答、相手の無言の観察 |
| **中断・終了・ケア** | 打撃が止まった瞬間を明瞭に切り、以後は落ち着いた文で余韻を残す | 本人の返答、美月の判断、残る痛み・疲れ、相手の声の近さ。直前の消耗を唐突に消さない |

### 音、擬音、比喩、身体反応

1. **擬音は選択的に使う。** 「バシッ」「ドスッ」などは場面の印象に合う場合の任意表現で、全ての拳に同じ擬音を付けない。音の大きさだけでパンチの威力・命中部位を決めず、どこへ当たったかと身体の反応を地の文で明らかにする。
2. **比喩は主人公の知覚に根差すものを優先。** 衝撃・息・重心・痛み・見失う視界などの具体性を先に書く。抽象的な強さの形容詞、「凄まじい」「圧倒的」などの反復で描写を代用しない。
3. **毎発同じ反応を書かない。** 息が詰まる、声が漏れる、肘が寄る、足が遅れる、反撃が出ない、相手を追う視線が途切れる等を、**その拳と以前の被弾との因果**に合わせて選ぶ。主人公が無敵・無表情にならないことはF21を優先する。
4. **痛みや驚きは主観、続行可能かは別の判断。** 継続の可否を擬音や大げさな比喩から自動判定しない。異変が見えた場合の打撃停止・本人の意思・美月の中断権・医療対応は裏スパールールの現行節と㉔が優先する。
5. **表と裏で人物の声を豹変させない。** 柚葉の明るさと短い高速連係、ひなたの短い指示と重い低い拳、その他メイドの話し方を保ち、地の文の速度は各人の戦い方と場面に合わせて変化させる。登場人物に「章」「演出」「嫉妬段階」等のメタ発言をさせない。

### 文体の簡易対照（固定本文・固定コンビネーションではない）

**説明が中心の旧い書き方の例：** 柚葉が左右のフックからボディへ連係すると、主人公はガードが遅れ、苦しくなった。

**F22で優先する体感中心の書き方の例：** 柚葉の左ショートフックがグローブを叩いた。受けた腕を引き戻す前に、今度は右の拳が横から迫る。そちらへ肘を寄せた瞬間、低いボディフックが腹へ届いた。息が詰まる。膝がわずかに緩み、伸ばしかけたジャブを戻すのが遅れた。柚葉はそこで拳を止め、彼の返事を待った。

**「必ず一発命中させる」「必ず音を付ける」という義務ではない。** 重要な攻防の因果が分かり、表情・動作・台詞から人物が立つことを最優先する。旧来の短い例文は技術の比較素材であり、この文体基準が上位。

## ㉔ F21補遺：被弾の事実と攻防の継続を分ける編集基準（2026-10-31整理）

F21の**「強打を受けて平然としていない主人公」**を本文で具体化するため、拳の一つひとつに次の**結果ラベル**を意識する。これは描写の分類であり、技を出せば必ず当たるという設定ではない。

| 結果 | 本文で確かめること | 誤読を避けること |
|---|---|---|
| **見せる／空振り／かわす** | 拳の軌道、距離、逃れた理由 | 音や驚きだけで命中済みにしない |
| **グローブ・前腕で受ける** | 当たったのは防具か身体か、腕や足へ伝わる負荷 | 「ガードした＝無傷」「ガードした＝腹へ直撃」の両極端にしない |
| **身体への明確な接触** | 拳の種類・部位・距離・衝撃・反射的な声や体勢 | 「ボディの軌道が見えた」だけで命中したことにしない |
| **次の拳／交代による累積** | 先の接触が次の構え・判断・反撃にどう響いたか | 状態の変化を無視して際限なく打ち続けさせない |
| **停止とその後** | 担当が拳を止めた瞬間、主人公の返答、美月の判断、余韻 | 苦しさを勝負の演出だけで消さず、事故も甘やかしだけで処理しない |

**フック／アッパーは拳の軌道名であり、顎・顔面への命中を自動的に意味しない。** 第14章の「上も使う」は「上向きの軌道を見せる・ガードに当たる・当日の確認範囲で扱う」等を本文で区別する。初回Lv.1の頭部打撃なしは維持し、特別回だからと頭部への危険な一撃を必須にしない。

### 連係と中断を矛盾させない

短い攻防の中で主人公が痛みに顔をしかめたり、一瞬息を詰めたりする**身体感覚の叙述**と、本人・担当・美月が把握する**継続可否の判断**を別の場面情報として書く。ただし前者は「軽いから続けて安全」という判定ではない。打撃を受けて返事が不確か、姿勢を保てない、呼吸や意識に異変、本人の中断希望、担当の判断の偏りなどがあれば進行を止める。迷う場合もいったん拳を下ろして確認し、確認後も続行の義務はない。異常を描くなら中断の遅れや見落とし自体が問題になることを物語に残す。

**本文の骨格**：拳の種類と起点→防御または命中→主人公の痛み・息・足・反撃→次の一手／拳が止まる理由→終了後の余韻。軽い体験・技術評価・本格的な山場では密度を変える。中断の具体的な運用は裏スパールール㉔と現行ルールが優先。


## ㉓ 改稿方針：強い被弾、コンビネーション、段階的な激化（2026-10-31採用）

**現行本文は書き直す前提。** 裏スパーの見せ場は、メイドの技術を外から説明することだけではなく、**主人公が実際に重みのある拳を受け、連係で削られ、平然としていられなくなる身体感覚**に置く。かわした拳・ガードした拳・身体へ命中した拳を曖昧にせず、主人公の近い三人称で知覚の順序を追う。

### 一連のパンチで必ず区別すること
1. **起点**：声・視線・踏み込み、拳の種類（ジャブ／ストレート／左右フック／アッパー／ボディ）、距離と角度。
2. **接触**：空振り、グローブや腕に当たる防御、脇腹や腹部への命中を分ける。どの攻撃が通ったのか読者に分かるようにする。
3. **受け手の反応**：衝撃で息が詰まる、反射的に肘が下がる、身体が折れかける、足が滑る、声が漏れる、視界から相手を見失う、返しが遅れるなどを、拳と結び付けて描く。すべてを毎回書くのではなく打撃ごとに選ぶ。
4. **次の一手と蓄積**：一発を受けて防御を直したところへ別の角度・高さ・間合いの拳が続く。「連打された」と省略せず、少なくとも重要な連係では前の被弾が次の防御失敗にどう影響したかを書く。
5. **終わりと余韻**：苦痛が表情・返答・呼吸・立ち姿に残る。休止・終了後も即座に無傷で普段どおりには戻さない。本人の意思と美月の中断判断、必要なケア・対応を場面に接続する。

**強さの描写は「大きい音を何度も書く」ことではない。** 単発の重さ、コンビネーションの速さ、呼吸を奪われる感覚、ガード越しの負荷、蓄積した疲れ、怖さと惹かれる気持ちを描き分ける。通常の軽い技術確認も残し、その対比で本格回を際立たせる。メイドたちは表の人格を失わず、台詞・目線・心配りと攻防の厳しさを両立させる。登場人物に構成上の用語を語らせない。

### 全8部にわたる激化の原則
- **第1部**：表営業、ミット、未知への期待。実際の被弾はまだ置かない。
- **第2部**：合意範囲の軽い初回接触。初めて拳を受ける驚き、ガード越しの音や足の揺れを明瞭に描く。
- **第3部**：柚葉の速攻と複数の軌道。防御の遅れが次の接触を呼び、明確な痛み・息の乱れ・TKO型の決着につながる最初の大きな山場。
- **第4部**：ひなたの重さ・正確さ・ボディ連係。瞬間的な連打より、立っていても呼吸と姿勢がじわじわ崩れる別種の厳しさ。
- **第5部**：柚葉→ひなたの対比回で攻め方の違いが重なる。疲労の持ち越しが判断を鈍らせ、第29章の中断に説得力を与える。
- **第6部**：朱音の評価、彩香・凛音の交代制、柚葉・ひなたの別日協力。主人公の防御と反撃も増えるが、それを上回る連係の複雑さで圧迫する。
- **第7部**：沙夜の少ない拳と長い沈黙を変化球とし、激しさを単調な威力増加にしない。
- **第8部**：本人と担当者・美月の確認が整って実施するなら、最多の技術・疲労・心理の集大成。第46章の多対1は実施確定ではなく、休息・変更も主人公の成長を示す。

**「後半ほど激しい」は作品の見せ方・技の組み合わせ・主人公の主観的負荷の大きな傾向であり、毎章の打撃威力を必ず上げる義務やLvによる危険打撃の許可ではない。** 通常の演出KOは意識を保つストップ／TKO型。実際の意識消失や頭部外傷は重大事故として別に扱う（裏スパールールの現行規定が優先）。個々の拳の順番・発数は執筆用の選択肢に留める。

## ㉒ 本文用の会話・呼称を暫定統一する編集手順（2026-10-30採用）

**会話の人物別正本は** `06_関係性・感情変化/【関係性】主人公・メイド関係図.md` の⑪・㉒。**既存の実例がある呼称（F10）を固定して守り、実例のない一人称・相互呼称・主人公への二人称はU10のまま暫定**にする。192場面案（48章構成⑳）は会話の機能を示す下書きであり、文章例を全て確定台詞と見なさない。

### 4場面プロットを会話本文に直す順序

1. **確定の台詞を先に置く**：柚葉の嫉妬A24・C25・D30、ひなたC29・D32に関わる本人と主人公の台詞は、原稿に流用する時も表現と発言順を守る。
2. **その場で本当に話す人物を選ぶ**：㉑の出演焦点は勤務表でない。見守るだけ・伝聞・回想の人物に、説明のための発言を自動追加しない。
3. **最初に話者の声を決める**：柚葉は明るい甘さ、ひなたは短い技術的な言葉、美月は丁寧で明確な停止、玲奈は軽口と責任の切り替え、朱音は技術と本人の感覚、彩香は勢いと謝罪、凛音は短い観察、沙夜は敬語と長い間。
4. **呼称は最後に補う**：既存の実例がある時だけその呼称を使う。未確認の対人呼称ではまず**呼びかけ・主語省略**を試し、それでも必要なら関係図㉒の**暫定第一候補**を使う。
5. **近さは語尾・間・返事で見せる**：同じ「ご主人様」、同じ「ひなたちゃん」のまま声の大きさや言い淀みを変えられる。表・裏、恋愛感情、専属の有無だけで呼び捨て・新愛称を決めない。
6. **地の文と発話の視点を分ける**：地の文は主人公に近い三人称（F13）で「彼」または主語省略。**会話の主人公一人称「僕」は必要時だけの暫定候補**であり、地の文を一人称に変える意味ではない。
