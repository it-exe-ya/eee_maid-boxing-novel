## 正本と編集の方針

1. 登場人物の外見・性格・口調はキャラクター設定、パンチや戦い方はファイトスタイル、心理の段階は感情変化を優先する。
2. 統合したファイルは元の題名と本文を下位見出しへ収め、重複する最上位見出しは整理した。古いファイルはGitの変更履歴から確認でき、旧資料は現行設定より優先しない。
3. `status: 確定`・`暫定`・`検討中` の状態を区別する。ファイル単位で「確定」でも、執筆用の例示・小場面は選択肢であり必須の出来事ではない。全8部48章の構成は暫定で、結末は未確定。
4. 変更時は [【管理】検討事項・変更履歴.md](99_作業・履歴/【管理】検討事項・変更履歴.md) に主要な履歴を残す。**確定済みF01〜F22／未確定・暫定U01〜U14**の判定表はこちらを正本とする。
5. ChatGPTの情報源に移すときは、使用する設定ファイルを選んで登録する。見出し・人物名・分類名は維持する。

## 旧資料・非採用案の判別（⑫の整理）

- **現行の定義は、各ファイルの「現行」「正本」「採用」節を優先**する。統合元ID、旧見出し、過去の確定記録は履歴として保持し、現在の設定へ自動復活させない。
- **非採用**：「安全な管理KO」や朱音の「管理KO可」、実際の失神を予定するKO回、Lv.4を危険な強打の許可とすること、表／裏で人格を別にすること。
- **未確定**：美月の最年長の序列、学園祭DAYの秋開催、全員の同日勤務、最終恋愛関係、未確認の愛称・呼称。
- **現行配置**：沙夜は第1章から表に登場し、第37〜42章に本格介入。KO回は意識が保たれたストップ／TKOの演出。初回招待の許可順は第5→6→7章。
- 旧案の詳しい判定は [【管理】検討事項・変更履歴.md](99_作業・履歴/【管理】検討事項・変更履歴.md) の**⑫旧案の判定表**を確認する。過去の変更履歴は改竄せず保存する。

- 柚葉とひなたは表／裏で別人格にならない。表の親しみやすさを残しつつ、リングでは技術と心理的な厳しさが増す。
- 柚葉はフック・アッパーを得意とする終幕・回収役、ひなたはボディ・非KOでの技術的な厳しさを持つ。
- 表の5イベントは現行48章案で**健康DAY（3章）、お仕事DAY（10章）、スポーツDAY（11章）、コスプレDAY（18章）、学園祭DAY（26章）**に配置。章内の細部は暫定。
- **第46章「連休中日・多対1の選択」**では、企画の実施は体調・意思・美月の判断により変更・延期・中止可能。旧章題「多対1ハード」を実施確定の意味に読まない。
- **⑭スパーの攻防・転換点・章末の引き**を48章構成の20章に追加。柚葉のフック・アッパー／ひなたのジャブ・ボディを対比し、主人公のガード・足・呼吸・自主判断を描く。具体的な連係の順序は**固定ではなく執筆用の選択肢**。参照先は48章構成⑭・ファイトスタイル⑭・イベント設定⑭。
- **⑮地の文は主人公に近い三人称を基本**。「彼」または主語省略で語り、スパー中の視点を主人公に固定。第5章だけは主人公不在の内部候補相談なので**柚葉視点の三人称限定**。ほかのメイドの独立視点は場面区切りを設けた場合の任意の執筆案。詳細は世界観⑮、48章構成⑮。
