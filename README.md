## 正本と編集の方針

1. 登場人物の外見・性格・口調はキャラクター設定、パンチや戦い方はファイトスタイル、心理の段階は感情変化を優先する。
2. 統合したファイルは元の題名と本文を下位見出しへ収め、重複する最上位見出しは整理した。古いファイルはGitの変更履歴から確認でき、旧資料は現行設定より優先しない。
3. `status: 確定`・`暫定`・`検討中` の状態を区別する。ファイル単位で「確定」でも、執筆用の例示・小場面は選択肢であり必須の出来事ではない。全8部48章の構成は暫定で、結末は未確定。
4. 変更時は [【管理】検討事項・変更履歴.md](99_作業・履歴/【管理】検討事項・変更履歴.md) に主要な履歴を残す。**確定済みF01〜F10／未確定・暫定U01〜U10**の判定表はこちらを正本とする。
5. ChatGPTの情報源に移すときは、使用する設定ファイルを選んで登録する。見出し・人物名・分類名は維持する。

## 執筆時の重要ルール

- 主人公の名前は原則出さず、必要時の表記は **○○**。
- 柚葉とひなたは表／裏で別人格にならない。表の親しみやすさを残しつつ、リングでは技術と心理的な厳しさが増す。
- 柚葉はフック・アッパーを得意とする終幕・回収役、ひなたはボディ・非KOでの技術的な厳しさを持つ。
- 表の5イベントは現行48章案で**健康DAY（3章）、お仕事DAY（10章）、スポーツDAY（11章）、コスプレDAY（18章）、学園祭DAY（26章）**に配置。章内の細部は暫定。
- 主人公の成長は**ジム経験のある対人初心者→ガード・距離・呼吸の改善→自ら希望と中断を選ぶ**方向。全8部の指針と重要章は主人公のキャラクター設定⑨と48章案を参照。
- 朱音・彩香・凛音・神崎沙夜には、技術評価と気持ちの理解／悪ノリの制御／観察の思い込みの修正／心理的な主導権と理解の区別という小さな成長を設定。人物設定⑩と48章案を参照し、中心三者の恋愛結末は変更しない。
- **人物間の呼称・会話**は関係図⑪を正本とし、各人物設定⑪で具体化。既存台詞の呼び方は維持する。主人公の「僕」や未記載の呼称は暫定で、親密になったからといって呼び捨て・恋人用の愛称に自動変更しない。
- 店の専属枠と個人的な恋愛関係は区別する。
- 初回の裏招待は**店内の候補検討（第5章）→本人への非公開説明と意思確認（第6章）→当日の美月の確認と玲奈の正式許可（第7章）**の順序。
- KO・頭部打撃を含む描写は**危険を伴うフィクション上の演出**であり、現実の安全な実施方法や頭部外傷の回復保証ではない。
