# Café Dulce Punch — 小説設定資料

本リポジトリは創作小説「Café Dulce Punch」の設定を管理するための正本です。

## 読み方
- **00_索引・管理**：全体索引、編集方針、確定／保留項目
- **01_作品設定**：世界観と執筆方針
- **02_店舗・運営設定**：店舗、運営、設備、制度
- **03_裏スパールール**：フィクション上のルールと安全・イベント規定
- **04_キャラクター設定**：主人公とスタッフの個別プロフィール
- **05_ファイトスタイル**：個々の戦い方と表現上の特徴
- **06_関係性・感情変化**：相互関係、嫉妬、対抗心、変化段階
- **07_イベント設定**：表・裏・合同・貸しリング等のイベント原案
- **08_ストーリー構成**：章構成案。設定確定後に再編集する
- **99_作業・履歴**：保留・改訂履歴

## ファイルの規約
ファイル名は `【分類】題名.md` とする。各ファイル先頭にはID、分類、確定状態を記す。基本設定は関連する各ファイルで重複させず、最も詳しいファイルを「正本」とする。

| 状態 | 意味 |
|---|---|
| 確定 | 会話で採用した設定 |
| 暫定 | 既存案から整理したが、まだ修正余地のある項目 |
| 検討中 | 未決定・矛盾確認待ち |

## 重要な前提
- 主人公の名前は原則本文で明示しない。必要時の表記は **○○**。
- 表と裏でメイドの人格は変えない。裏では表の性格の延長として、リング上の容赦のなさが強くなる。
- 「専属」は店内の緩い管理枠、「恋人」は私的関係として区別する。
- 終盤の着地点は固定しない。
- 作中のKO・頭部打撃・高負荷スパー等は**フィクション上の演出**であり、現実に安全な実施方法を示すものではない。実際の意識消失は重篤な頭部外傷の可能性があり、休日・防具・支え手などで安全になるものではない。

## 編集の順序
1. `00_索引・管理/【索引】設定総覧.md` で関連ファイルを探す。
2. 正本となる設定ファイルを変更する。
3. 依存する関係性・イベント・章構成へ反映する。
4. `99_作業・履歴/【履歴】設定変更ログ.md` に主要な変更を記載する。

この構成は、後でChatGPTのプロジェクト情報源に登録しやすいようにしています。
