# 柚葉・ひなた

## 【ファイトスタイル】天川柚葉

> 旧ID: `FIGHT-YUZUHA`


### スタイルの定義
**スピードKO型／近〜中距離のフック・アッパー**

### 技術的な特徴・得意距離
空手・ボクシングの経験を活かし、踏み込みと回避、カウンター、密着連打を得意とする。小柄ながら速度とパワーの両立を目指す。打たれることには弱い面があり、先に位置を取る。

### 得意なパンチ
左右のフック、ショートフック、アッパー、ショートアッパー、ボディフック。顔面打撃は特別な裏回に限定される物語上の要素。

### 攻防のテンポと心理
素早い接近、短い連打、角度の変化、間合いを潰す攻防。初期は反応を確かめ、嫉妬時は笑顔のまま動きが鋭くなる。


### 代表的な攻防の基本方針（2026-10-29採用）
**スピード・近距離・角度変更・短い連打。** 柚葉は笑顔や軽口を保って距離を詰め、フックとアッパーの異なる軌道を使う。空手とボクシングの経験は素早い踏み込みやカウンターに表れる。攻撃だけでなく、反撃をかわす足運びと打たれ弱さも描く。

#### 代表パターン（場面に応じて選ぶ描写例）
| 攻防 | 動き・パンチの特徴 | 物語での役割 |
|---|---|---|
| 軽口からの先手 | 明るい声に続く軽いジャブと短いストレート。拳を戻す速さと主人公の構え直しを描く | 序盤の柚葉らしさ |
| 左右ショートフック | 左右の肩が交互に動き、近距離でコンパクトな弧を描く。主人公はガードを寄せ直す | 主力の連打 |
| ボディフックと横への移動 | 低い位置へのフックの後、同じ正面に留まらず横へ動く。主人公は彼女の位置を追う | 足運び・距離感 |
| スリップからカウンター | 主人公のジャブが伸びると、上体を小さく外し、間を置かず短い拳を返す | 空手・ボクシング経験の差 |
| ショートアッパー | 身体が近くなった時、拳の軌道が下から上へ変わる。フックとは違う距離感を強調 | 得意技の個性 |
| フェイントとからかい | 肩や目線をわずかに動かし、防御した主人公を見て笑う。予想していた次の動きを変える | 「反応が可愛い」心理 |
| 返される攻撃 | 主人公のジャブが思いがけず届き、柚葉の足が一瞬止まる。むっとしてガードを直す | 打たれ弱さ・負けず嫌い |
| 終幕と回収 | 攻防が区切られた瞬間に拳を下ろし、すぐ主人公の顔や返事を気にする | 柚葉の独占欲と優しさ |

#### 防御・弱点・疲労時の癖
- **守り**：小さなスリップ、横への一歩、ガードの上げ直し、間合いを外してからのカウンターが得意。腕を固めて長く正面で受け続けるのは苦手。
- **受けた時**：実際に反撃を受けると、得意げな笑顔が一瞬崩れ、負けず嫌いな表情が出る。いつも必ず先手を取れるわけではない。
- **疲労**：戻り足が鈍くなり、短いフックの軌道が広がる。肩の上下や呼吸の間が大きくなり、軽口が少し増えることもある。
- **焦り**：ひなたへの嫉妬で笑顔のまま踏み込みを急ぎたくなる。ただし感情の強さを危険な打撃の解禁には結びつけず、美月の中断を描く。

#### 時期による変化
- **第7〜12章**：軽いジャブ・短いフック・素早い退避。主人公の反応を見て楽しむ。
- **第13〜18章**：フックとアッパーが「自分で終わらせて回収する」象徴になる。通常の演出KOは意識消失を伴わないストップ／TKO型。
- **第24〜30章**：嫉妬A→C→D。技より先に動こうとする気持ちや、反応を見落としそうになる危うさを描く。
- **第33〜35章**：ひなたの担当範囲を尊重し、自分の得意な接近・角度変更・終幕に集中する。

#### 拳と足の描写例
> 「えへへ、見ててくださいね」。柚葉の左ジャブがすっと伸び、主人公のグローブが上がる。直後、肩が横へ回り、短いフックが弧を描いた。主人公が腕を寄せた頃には彼女の足は半歩外へ移り、ポニーテールだけが遅れて揺れる。「今の、ちゃんと見えました？」。明るい声はいつもと変わらなかった。


### 終了・KO傾向
『自分が終わらせ、自分が回収する』ことに強い意味を持つ。通常の「KO回」は意識消失を伴わないストップ／TKO型の演出上の決着とし、実際の失神は重大事故として別に扱う。支えることだけで頭部打撃が安全になるわけではない。

### 口調例
『じゃあ今日は、ちょっと強めにいくね』『今日は私の番だから』『よく頑張ったね』

### 他キャラとの組み合わせ
ひなたと対立した後は、ひなたが継続的な攻防を担当し、柚葉が感情的な終幕と回収を担う。

## 【ファイトスタイル】桐生ひなた

> 旧ID: `FIGHT-HINATA`


### スタイルの定義
**ボディ管理型／非KO耐久・姿勢制御**

### 技術的な特徴・得意距離
空手・キックの基礎を持ち、まっすぐな姿勢と間合いの観察を重視。単純な攻めより、相手がいつ息を乱し、どこで構えが崩れるかを見抜く。

### 得意なパンチ
ジャブ、左・右のボディブロー、ボディストレート、近距離の短いパンチ。フック・アッパーのKO演出では柚葉を立てる。

### 攻防のテンポと心理
短い指示、正確なテンポ、姿勢を見ながらの継続的な攻防。対抗心が高まると技術的な厳しさに感情がにじむ。


### 代表的な攻防の基本方針（2026-10-29採用）
**正確なジャブ・直線的な打ち分け・ボディ・姿勢観察。** ひなたは柚葉のように一気に踏み込んで終幕を作るより、中距離で主人公の構えや足元、呼吸を観察する。空手・キック経験は重心と距離感に表れ、裏では基本的に拳による攻防を描く。

#### 代表パターン（場面に応じて選ぶ描写例）
| 攻防 | 動き・パンチの特徴 | 物語での役割 |
|---|---|---|
| 単発ジャブの確認 | 一度だけ拳を伸ばし、「今の、見えた？」とガードと返事を確かめる | 代役初回の指導者らしさ |
| ジャブのテンポ差 | 同じ直線の拳でも一発目と二発目の間が違う。主人公は反応の遅れに気づく | 柚葉の速い連打との差 |
| ストレートとボディストレート | 真っ直ぐな拳の動きを見せてから、低い位置へ打ち分ける。主人公の視線とガードの変化を描く | 精度・観察力 |
| 左右のショートボディ | 大きく振りかぶらない短い動き。手数より主人公の姿勢や呼吸の変化を重視する | 非KOのボディ主体 |
| 主人公の返しを受ける | 主人公のジャブやワンツーをガードとステップで処理し、「その一歩はいい」と評価する | 主人公の成長 |
| 間を置くジャブ | 次の拳を急がず、構えを直す主人公を見て静かに待つ。短い指示が緊張を生む | 技術的な厳しさ |
| 読み違いを認める | 主人公の状態を見誤ったら拳を下ろし、「今のは私が悪い」と言う | 技術への自負の弱点 |
| 非KOの終了 | 主人公が立っていても合図や状態によって中断。ひなたはまず返事を確認する | 「立てる」と「続けてよい」の区別 |

#### 防御・弱点・疲労時の癖
- **守り**：高いガード、前腕・グローブでの受け、距離の微調整、相手のジャブに合わせたステップ。立ち位置の安定が持ち味。
- **苦手**：柚葉のような急な角度変更や、予想外の返答・感情への対応。相手を「理解している」と思い込むことがある。
- **疲労**：ジャブの戻りと足の動きに小さな遅れが出る。指示する前の呼吸が長くなる。完璧に崩れない人物にはしない。
- **動揺**：技術的な説明が増え、言葉が短くなる。感情を攻撃力の増大で示すのではなく、言い切り方や沈黙で示す。

#### 時期による変化
- **第19〜23章**：単発ジャブと姿勢確認。「一回だけ」の代役なのに反応が気になり始める。
- **第27〜29章**：主人公を理解している自負が対抗心に変わり、「まだ立てる。私には分かる」（感情C）が出る。美月の判断を優先する。
- **第32章**：主人公から「次、ひなたさんでも……大丈夫です」と希望され、「……軽く言わないで」（感情D）と動揺。ここは**会話中心**で、すぐに攻防を始めない。
- **第33〜35章**：ひなたは継続的な攻防の見方と姿勢の確認、柚葉はスピードと終幕という役割を尊重する。

#### 拳と視線の描写例
> 「はい、構えて」。ひなたの左ジャブが一度だけ伸びた。主人公がグローブを上げると、彼女は次を打たずに足元を見た。「今、右足止まった」。彼が下を見る間もひなたは距離を保ち、息を整えるのを待つ。「急ぐな。まず足」。いつもの気さくな声のまま、拳を下ろして返事を確かめた。


### 終了・KO傾向
原則非KO。『まだ立てる』という本人の判断が過剰になりうるため、美月が『立てることと続けてよいことは違う』と制止する。

### 口調例
『はい、構えて』『息』『まだ立てる。私には分かる』『……軽く言わないで』

### 他キャラとの組み合わせ
柚葉と競合するが、最終的には削りと調整を担う別の相手として認められる。

### 48章を通じた書き分け
- **序盤**：ジャブとガード、接近や回避の違いをゆっくり描き、主人公の経験不足を示す。
- **中盤**：主人公の返しや防御も増やす。同じ種類のパンチでも距離、速さ、音、拳の戻りを変えて書く。
- **対比イベント**：柚葉の「横方向の弧・角度」とひなたの「直線・リズム・姿勢」の違いを、主人公がどう感じるかで比較する。
- **協力イベント**：交代制にし、ひなたの管理的な視線から柚葉の終幕・回収へ役割を受け渡す。
- **長編全体**：同じ連係を毎回繰り返さず、一場面で中心の技を2〜3種類選び、拳の動き・ガード・足さばき・台詞・返事を交互に描く。

### パンチごとの描写上の区別
- **ジャブ**：拳の直線的な伸び、短い戻り、間隔の違い。
- **ストレート**：真っ直ぐな軌道、肩の動き、構えへの接触音。
- **フック**：横方向の弧、肩の回転、守る腕の寄せ方。
- **アッパー**：近い距離で変わる上向きの軌道、視線と腕の角度。
- **ボディブロー**：低い位置のグローブ、息や姿勢の変化、踏ん張る足。
- **カウンター・フェイント**：相手の動作と返す動作の時間差、見せかけに反応した時の目線。

### 共通ルール
ここに記した連係は**小説内の描写の選択肢**であり、毎回順番通りに実施する固定メニューではない。通常の「KO回」は意識消失を伴わないストップ／TKO型の演出。実際の失神は重大事故として扱う。主人公とメイドの参加意思、美月の中断権が最優先。感情の高まりを危険な打撃の許可条件としない。表と裏で性格が別人格に変わる描写をしない。
