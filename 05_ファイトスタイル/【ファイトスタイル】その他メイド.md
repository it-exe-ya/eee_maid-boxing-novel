# その他メイド

## ㉕ F22 周辺メイドの場面別・文章テンポ（2026-10-31採用）

中心二人と異なる攻防の**語り方**を維持する。拳の種類・命中・主人公の反応はF21・㉔に従い、各人を同じ強打連打型にしない。

| 人物 | 地の文のリズム | 台詞と身体感覚の焦点 |
|---|---|---|
| **朱音** | 構え、拳の戻り、技術的な差を落ち着いた正確な文で書く | 具体的な改善点と主人公の実感を結ぶ。第31章の基準確認を強打やKOの実演にしない |
| **彩香** | 会話の勢い、近距離のショートボディの一発、急に拳を止める瞬間に緩急 | 音・漏れた声・謝り方。擬音の多さだけで陽気さを代用しない |
| **凛音** | 短文と空白。打つふりの前後に視線と反応のずれを置く | フェイントと実際の接触を区別。相手の感情は断定せず尋ねる |
| **沙夜** | 少ない短い拳に対して、沈黙や返答の遅さを相対的に長く描く | 心理的な緊張と身体への命中を混同しない。万能の読心者にはしない |
| **美月** | 状態を見る視線から短く明瞭な終了の言葉へ切り替える | 劇的な追加打撃の役ではなく、本人の返答と中断判断を中心に書く |

**玲奈の表の声**は関係図㉕で運営判断との切り替えを参照する。本文の一文の長さや擬音回数を人物ごとに数値固定しない。

## ㉔ F21補遺：脇役の一発と停止の役割（2026-10-31整理）

- **朱音（31章）**：フォーム比較が主。軽い実技確認でもガードに当たる感触・姿勢変化は書けるが、評価のための強打・管理KOを必須にしない。
- **彩香（34章）**：近距離のショートボディが身体に届いたか、グローブに止められたかを音と主人公の声で区別。疲れや不安が見えたら「もう少しだけ」より区切りを選ぶ。
- **凛音（34章）**：フェイントは命中ではない。実際に当たった短い一発があれば、予想と現実のずれを主人公の驚きとして描く。彩香より拳を増やさない。
- **沙夜（39〜42章）**：沈黙による心理的な圧迫と少数の短いボディを分け、拳のない時間を被弾回数に数えない。本人の返答保留を拒否・中断可能性の消失にしない。
- **美月**：相手を打ち倒す人物でなく、反応に迷いが生じた時も打撃を止める判断の担当。別のメイドの声・技術評価・観察を本人の希望と照合し、優先的な停止権を保つ。


## ㉓ 強打・連係描写の個別差（2026-10-31採用）

中心二人以外の裏の見せ場でも、拳の種類・命中・受け手の反応を省略しない。**すべてのメイドを同じ激しい連打型にはしない**。

| 人物 | 主な攻めと連係の印象 | 主人公の被弾・消耗の見え方 |
|---|---|---|
| **朱音** | きれいなジャブ→ストレート／ワンツー、正確なボディストレート。無駄のないフォームと距離で技術差を示す | ガードの隙を突かれ、腕に受ける衝撃と姿勢のずれで技術差を実感。第31章は攻撃で倒す回でなく、改善点の評価が中心 |
| **彩香** | 軽口と速いテンポ、近距離のショートボディと左右の短い打ち分け | 拳の音と同時に息や声が漏れ、身を縮めると次の一発への反応が遅れる。第34章は疲れの申告を受けて自分から区切る |
| **凛音** | 視線・肩・フェイントでガードを先に動かし、間を外した短い単発・少数の連係 | 「来る」と思って固めた側とは違う場所で衝撃を感じ、顔に驚きが出る。彩香のような手数を頼みにしない |
| **沙夜** | 少ないショートボディと長い間。沈黙のあとの不意の打撃 | 待つ間に呼吸が浅くなり、一発が実際より強く感じられる。大量の被弾ではなく緊張と予測不能さが負荷 |
| **美月** | 原則攻撃を増やさず、呼吸・反応・姿勢・本人の意思を確認 | 主人公の様子が変わった時に拳を止める役。劇的な打撃役に置き換えない |

**強度の役割**：34章の彩香・凛音の交代制は「柚葉・ひなたと違う身体反応」を見せる機会。朱音は基準を測り、沙夜は心理的に削る。第46章の出演・攻防は全員分を確定せず、実施条件が整った場合のみ最も多彩な連係の素材として使う。従来の「管理KO非採用」「非KO」「美月の優先的な中断判断」を維持する。


## ⑭ 脇役の攻防・観察・章末の演出（2026-10-29採用）

| 人物・章 | 主な拳の見え方と主人公の反応 | 心理的な転換・場面の終わり |
|---|---|---|
| **朱音・第31章** | 正確なジャブ、右ストレート、ワンツーを**フォームの基準として見せる**。主人公の拳の戻り、横の一歩、ガードを第3・11章と比較 | 「前よりできている」を伝えるだけでなく本人がどう感じたかも聞く。**管理KOはしない**。主人公の第32章の自主的な再指名へ |
| **彩香・第34章** | 明るい声と短いボディの音・息の変化。主人公が疲れたと申告したら拳を引き、交代を提案する | 悪ノリだけで終わらず、自分から止める成長。凛音に場を渡す |
| **凛音・第34章** | 短い単発とフェイント。主人公が視線を逸らしてガードを寄せても、その反応を断定しない | 「嫌だった？」と本人に尋ね、観察は読心と違うと示す |
| **神崎沙夜・第39〜42章** | 少ないショートボディと長い間。パンチを打たない空白、呼吸の音、視線のずれが中心 | 主人公が返答を保留したら待つ。第41章でひなたの率直さに驚き、第42章で美月の中断を尊重 |
| **美月・各回** | 軽い技術確認が必要な時以外は積極的に打ち合わず、拳の戻り・呼吸・返事・本人の意思を見る | 一番強い拳よりも「ここまでです」という停止判断が物語の転換点になる |

**本文を描く際の区別**：彩香はパンチ音と声、凛音はフェイントと視線、朱音は安定した姿勢と技術比較、沙夜は沈黙と質問、美月は停止の判断。連打の量を増やすことを「役割が違う」根拠にしない。各章の詳細な攻防と引きは `08_ストーリー構成/【構成案】全8部・48章.md` の⑭。出演・交代の細部は本人の希望と当日の条件次第で変更可能。

## ⑫ 旧ファイト案の現行判定（2026-10-29採用）

- **朱音**：旧案の「管理KO可」は**採用しない**。現在は技術基準・正確なフォーム・評価・本人の感じ方を確認する役で、意識消失を管理・保証する設定ではない。
- **柚葉**：「スピードKO型」はキャラクターの**演出上の呼称**。意識を失わないストップ／TKO型の終幕と、意識消失を伴う事故を区別する。
- **ひなた**：「非KO耐久」は攻防の技術的な性格を表す。立位を保っているだけで無期限に続けられる設定ではない。
- **美月**：技術基準役や朱音の「管理KO」ではなく、本人の意思・当日の状態を優先して店内の進行を止める担当。
- 旧ファイルIDは統合元の追跡に使う**資料名・識別子**であり、過去の案を自動で復活させる意味ではない。確定したKO・Lv・同意・中断の区別は `03_裏スパールール/【裏スパールール】基本・イベント・安全管理.md` を優先する。
