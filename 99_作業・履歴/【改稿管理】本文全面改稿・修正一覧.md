## 3. 進捗の記入ルール

| 項目 | 記入方法 |
|---|---|
| **優先度** | **最優先**＝主な攻防山場・固定台詞と連続性の要点、**高**＝主要な人物・物語上の転換または停止判断、**中**＝日常・橋渡し・伏線の文体調整。優先度は執筆順の強制ではない |
| **状態** | **原稿未照合** → **改稿対象を確定** → **改稿中** → **本文反映済み** → **正本照合済み**。必要なら**保留（未決定の演出）**。本文を見ていない段階で「要修正」と決めつけない |
| **チェックボックス** | チェックは**章別の本文・正本照合が終わった時だけ**入れる。初期は全48章とも未チェック |
| **記録** | 各章の改稿後に「対象段落・変更点・守った固定条件・残課題・確認日／版」を記録する。確定事項の変更は管理の別記録へ |
| **候補の扱い** | 「強化案」「実施するなら」「候補」は設定変更・実施決定ではない。採用しなくても対応する心理・関係の章目的を果たせればよい |
